# Story Mood Playlist 🎵📖

A Chrome extension that suggests Spotify playlists based on the mood of the content you're reading.

## Features ✨

- **Mood Detection**: Analyzes webpage text to detect emotional tone
- **Spotify Integration**: Suggests playlists matching the detected mood
- **Custom Filters**: Refine by genre (Pop, Rock, K-Pop, etc.) and language
- **Beautiful UI**: Purple-themed interface with smooth animations
- **PKCE Security**: Secure Spotify authentication flow

## How It Works 🔍

1. Click the extension icon while reading any article/story
2. The AI analyzes the text's emotional tone (Happy, Sad, Romantic, etc.)
3. Get a curated Spotify playlist matching the mood
4. Refine with genre/language filters if desired
